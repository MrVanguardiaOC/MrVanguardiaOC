01 / Estudio
Soy Elvis Manuel — fundador de OFICIO CERO, estudio independiente de software e ingeniería digital basado en Esperanza, República Dominicana.

Construyo sistemas de extremo a extremo: desde el esquema de base de datos hasta el último píxel del botón. Disfruto escribir código que dure, documentar las decisiones difíciles y discutir arquitectura con gente curiosa. Programa con IA como parte del flujo diario, sin sustituir el criterio técnico propio.

Stack histórico: SaaS, ERP/CRM/POS, facturación electrónica DGII (e-CF), automatización, APIs, PWA offline.
Hardware real: diagnóstico automotriz (CAN Bus, K-Bus), impresoras térmicas, POS, montaje de PCs.
Infra: Linux/Fedora como sistema principal, Cloudflare, hosting y DNS, firma digital RSA-SHA256.
Reconocimientos: GitHub Developer Program · Google Play Academy Ignite · Ciberseguridad Intermedio (Talento Digital/BID).
